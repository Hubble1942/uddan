# Not optimised for eInk yet

Uddan will eventually run on a color eInk reader, but it is built and tuned as an ordinary browser app for now. The device generation we're aiming at isn't available yet (first devices are expected in 2027), and its refresh behaviour, palette, ghosting and browser engine are unknown. Optimising for guessed constraints would be wasted effort that would likely need to be redone. Once a real device is in hand, we optimise for its measured behaviour.
